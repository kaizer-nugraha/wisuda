# Cara Memasukkan Foto

Simpan foto di folder ini (`images/`) dengan nama berikut (format .jpg):

| Nama file         | Tempat tampil                          | Saran foto                     |
|-------------------|----------------------------------------|--------------------------------|
| foto-utama.jpg    | Bingkai besar di bagian "Ucapan"       | Foto Ikka memakai toga (potret)|
| foto1.jpg         | Galeri – kotak besar                   | Hari wisuda                    |
| foto2.jpg         | Galeri                                 | Awal kuliah / mahasiswa baru   |
| foto3.jpg         | Galeri                                 | Praktik klinik / seragam bidan |
| foto4.jpg         | Galeri – kotak tinggi                  | Bersama teman seperjuangan     |
| foto5.jpg         | Galeri                                 | Sidang skripsi                 |
| foto6.jpg         | Galeri – kotak lebar                   | Foto kalian berdua             |

Kalau file belum ada, halaman otomatis menampilkan bingkai "Tambahkan foto".
Mau pakai .png? Ganti juga nama file di `index.html` (cari `images/`).

Musik (opsional): buat folder `music/` lalu simpan lagu sebagai `music/lagu.mp3`.
